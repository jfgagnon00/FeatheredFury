La majorité des opérations répétitives sont encapsulées dans une une interface au command line. 

Format général du command line:
```
ffury [OPTIONS_GLOBALES] [COMMAND] [OPTIONS_SPECIFIQUES] ARGUMENTS
```

Pour bbtenir de l'aide:
```
ffury --help
ffury [COMMAND] --help
```

La commande la plus usuelle. Obtenir le dataset:
```
ffury dataset install
ffury dataset preprocess
ffury dataset index
```
